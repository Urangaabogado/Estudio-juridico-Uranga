# Estudio Jurídico Uranga

Sitio web estático para GitHub Pages.

## Cómo usar
1. Descomprimir el ZIP.
2. Subir `index.html`, `styles.css` y `README.md` al repositorio.
3. Activar GitHub Pages desde Settings > Pages.
